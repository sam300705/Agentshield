# Code of Conduct

AgentShield is committed to a respectful, constructive, and safety-conscious community. Participants are expected to communicate professionally, assume good faith while checking facts, welcome different perspectives, and focus criticism on ideas, code, evidence, and behavior rather than people.

Unacceptable behavior includes harassment, discrimination, threats, intimidation, doxxing, sexualized conduct, deliberate disruption, publication of private information, malicious security testing, and submitting real customer or sensitive data. Security vulnerabilities must be reported privately according to [`SECURITY.md`](./SECURITY.md).

Maintainers may remove content, request changes, restrict participation, or close discussions when necessary to protect contributors, users, or the project. Enforcement should be proportionate to the behavior and documented where appropriate.

To report a conduct concern, contact the repository maintainers privately through GitHub. Do not include passwords, tokens, private keys, customer information, or other secrets. If the concern is a security vulnerability, use the private process in [`SECURITY.md`](./SECURITY.md).
