## Compatibility and migration

`assertAgentActionAllowed` now takes `AgentAuthorizationRequest` as its first argument, replacing the action string. Callers must pass exactly the request whose evidence/resource they will execute, plus the corresponding decision and reviewed approval. Do not reuse a reviewed approval after changing command evidence.

The new append-only migration `20261008120000_scan_cancellation_audit` adds one audit enum value. Existing migration files and persisted history are unchanged. Apply with the existing incremental deployment procedure. The populated-database upgrade CI gate must pass on the published commit before this remediation is considered code-complete.

Local verification and exact-head CI results are recorded in PR #9. Local Docker/PostgreSQL are unavailable: real database, populated upgrade and container checks are CI requirements, not locally claimed results. CI passing does not establish independent security acceptance, owner configuration or live-provider verification.
