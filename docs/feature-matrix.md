## Remaining boundaries

The safe repository work is implemented as far as possible without owner credentials or external authorization. Remaining work includes registering and installing a GitHub App, configuring a real OIDC provider and exact HTTPS redirects, deploying the API/worker/database, connecting a shared Redis-compatible store, selecting an approved OSV outage policy, configuring production signing custody, running live smoke tests, and merging only with owner approval. Docker must still be built and inspected in a Docker-enabled environment.
